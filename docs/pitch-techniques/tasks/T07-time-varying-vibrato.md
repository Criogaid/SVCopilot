# T07 — 时变颤音模型

- 状态：`ready`
- 权威：[实施计划](../implementation-plan.md) F3b、F9、§8、§17 提交 7
- 依赖：T01 corpus
- 解锁：T09

## 目标

实现固定与时变 rate 的秒域颤音模型，确保相位积分、fade、span 和振幅在全部公开边界内稳定。

## 交付边界

- 公开字段和默认值只从权威计划读取；本文件不创建替代契约。
- 实现 envelope 连续性、有限相位、有限输出和过短 span 拒绝。
- 覆盖固定 rate 与时变 rate 的退化一致性。
- 不决定原生 `vibratoEnv` 共存策略，该决策来自 T04/H2。

## 验收

- reference 的过零点、零输入、极值、fade 和非法关系测试通过。
- rate/span/phase 极值只产生有限结果或结构化错误。
- 性能证据与 T05/T06 使用相同采样规模和统计口径。

## 完成条件

颤音 primitive 可进入 T09，且宿主共存未知量仍保持显式 gate。
