# T19 — 条件单 Undo 有界闭环

- 状态：`conditional`
- 权威：[实施计划](../implementation-plan.md) §14、§17 提交 19
- 依赖：T04/H5/H7 通过；T15、T18 通过全部发布前提
- 解锁：T20 的可选闭环能力

## 目标

仅在安全门禁成立时，把有限次测量与修正封装为一个 operation、一个 coordinator 和一个 Undo 边界。

## 交付边界

- 实现权威状态机、预算、候选耗尽、journal 和不可证明终态。
- 不允许客户端用多个 commit 编排冒充单 Undo 闭环。
- 任一发布前提失败时不注册 operation，项目仍以开环能力发布。
- 迭代详情默认外置，主响应只保留决策和恢复状态。

## 验收

- 每个 setter、等待、比较、候选和 rollback 故障点均可注入。
- 真机确认整个成功闭环只占一个用户 Undo，断连不会谎报恢复。
- 预算耗尽、无改善和证据不足有不同终态且禁止危险重试。

## 完成条件

全部条件证据成立才标记 `done`；否则记录 `not_enabled`，不降低事务标准。
